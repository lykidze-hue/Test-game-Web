# Тайны Тихой Заводи

Тестовая WebGL-сборка игры для настольного браузера.

## Запуск на Windows

1. Скачайте ZIP через **Code → Download ZIP** и распакуйте его.
2. Запустите `Start Game.cmd`. Скрипт откроет игру по адресу `http://127.0.0.1:8765/`.
3. Оставьте окно сервера открытым, пока играете.

Для локального запуска нужен Python 3. Подойдёт Python из Unity 6000.6.8f1 или Python, доступный через команду `python`.
